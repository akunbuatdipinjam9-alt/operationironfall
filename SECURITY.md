# Security Policy

## Yo, found something suspicious?

First of all, thanks for helping keep **Operation Ironfall** safe.

We're a small indie project developed by **Afternight Games**, and yeah, we're still learning and improving things.

Security matters, especially when you've got multiplayer servers, player connections, and a bunch of JavaScript doing its thing.

So if you find a security issue, here's what you should do.

## Reporting a Vulnerability

Found a security vulnerability?

Cool catch. But please don't post it publicly just yet.

If GitHub's private vulnerability reporting feature is enabled for this repository, use the **Report a vulnerability** option under the Security tab.

Otherwise, contact the maintainers through a verified private contact method listed on the repository profile.

Please include:

- What the vulnerability is.
- Which part of the game is affected.
- How the issue can be reproduced safely.
- What could potentially happen.
- Any relevant screenshots or logs.

Please remove passwords, tokens, and personal information from your reports.

## Please Don't Do This

We appreciate security research, but there are some boundaries.

- Don't attack the live game server.
- Don't access other players' accounts or private data.
- Don't attempt to disrupt multiplayer matches.
- Don't perform stress tests against production infrastructure without permission.
- Don't publicly share vulnerabilities before coordinating with the maintainers.

If you wanna test something, use your own local environment.

We're trying to fix bugs, not create new disasters.

## What Happens After Reporting?

We'll review the report and try to determine its impact.

If the vulnerability is confirmed, we'll work on a fix and coordinate disclosure when appropriate.

Response times may vary because this is an independent project.

We can't promise instant fixes, but legitimate security reports are appreciated.

## Supported Versions

Security fixes are primarily intended for the latest actively maintained version of Operation Ironfall.

Older versions may not receive updates.

## One Last Thing

Security is everyone's responsibility.

Whether you're contributing code, testing features, or just playing the game, please help us keep the community safe.

Thanks for looking out for Operation Ironfall.

**Afternight Games**

*Build cool stuff. Don't break other people's stuff.*
