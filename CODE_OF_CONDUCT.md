# Code of Conduct

## Welcome to the Chaos

Hey, welcome to the **Operation Ironfall** community.

We're building a browser FPS, experimenting with weird ideas, fixing bugs, and occasionally wondering why the server decided to crash again.

But here's the thing.

Just because our development process is chaotic doesn't mean our community has to be.

So let's keep things fun.

## Rule #1: Don't Be a Jerk

Seriously. That's basically the main rule.

We're all here because we enjoy games, programming, and building cool stuff.

You don't have to agree with everyone, but you do have to treat people with respect.

Here's what we expect:

- Be respectful to other developers and players.
- Give constructive feedback.
- Help newcomers when you can.
- Respect different opinions and skill levels.
- Keep discussions relevant.
- Give proper credit when using someone else's work.

And yeah, jokes are welcome.

Just don't use humor as an excuse to harass people.

## Rule #2: Criticism Is Fine

Think our code looks terrible?

Fair enough.

Found a bug that makes absolutely no sense?

We've probably seen worse.

You're allowed to criticize the project, suggest changes, and disagree with development decisions.

Just explain your reasoning.

"Your code is trash" doesn't help anyone.

"This function causes unnecessary server load, and here's how to improve it" is way more useful.

See the difference?

## Rule #3: Stuff We Don't Allow

Let's make this clear.

The following behavior isn't welcome:

- Harassment, bullying, or discrimination.
- Threats or intimidation.
- Hate speech or targeted personal attacks.
- Sharing someone's private information without permission.
- Spam, scams, or malicious links.
- Deliberately disrupting community discussions.
- Posting malicious code disguised as legitimate contributions.
- Repeatedly ignoring moderator instructions.

We're making a game, not running an internet battlefield.

Well, technically the game is a battlefield.

You get the point.

## Rule #4: Respect Other People's Work

Operation Ironfall is publicly available under its applicable licenses.

That doesn't mean everything belongs to everyone.

Respect copyright notices, asset restrictions, and the licensing terms established by Afternight Games.

Don't claim someone else's work as your own.

If you use another contributor's work, give them proper credit.

## Rule #5: Keep Contributions Useful

Wanna submit a Pull Request?

Awesome.

But please:

- Explain what you changed.
- Test your changes.
- Avoid unrelated modifications.
- Don't intentionally introduce vulnerabilities.
- Be open to feedback.

Not every contribution will be accepted, and that's okay.

Sometimes an idea doesn't fit the project.

It's nothing personal.

## Reporting Problems

If someone violates this Code of Conduct, contact the maintainers privately through a verified contact method listed on the repository.

Include relevant details and evidence when possible.

Please avoid publicly sharing sensitive personal information.

Security vulnerabilities should be reported using the process described in `SECURITY.md`.

## What Happens If Someone Breaks the Rules?

Depending on the situation, maintainers may:

1. Give a warning.
2. Remove inappropriate comments or contributions.
3. Temporarily restrict participation.
4. Permanently ban someone from project spaces.

Serious violations may result in immediate restrictions.

Moderation decisions should be based on the behavior involved, not personal disagreements.

## Where These Rules Apply

This Code of Conduct applies to official Operation Ironfall community spaces, including:

- GitHub Issues
- Pull Requests
- Discussions
- Other official project communication channels

It also applies when someone is officially representing the project.

## Final Words

Look, we're not trying to create a community with a thousand complicated rules.

We just want people to enjoy building something together.

You can joke around.

You can disagree.

You can tell us our bots are dumb.

Just don't make the community miserable for everyone else.

That's it.

**Thanks for being part of Operation Ironfall.**

Developed by **Afternight Games**.

*Write code. Fix bugs. Respect people. Repeat.*
